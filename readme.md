# Casino 🎲

Een eenvoudige client-side casino-webapplicatie, ontwikkeld door Bergerbot / NickD-01.

Bezoek de live demo: [https://nickd-01.github.io/Casino/](https://nickd-01.github.io/Casino/)

---

## Overzicht

- Het project draait volledig in de browser (HTML, CSS, JavaScript) — geen backend nodig.  
- Momenteel gaat het om het spel **Blackjack**: de speler tegen de dealer.  
- De interface toont de dealerhand, spelerhand en knoppen voor acties (“Add Player”, “New Game” etc). :contentReference[oaicite:1]{index=1}  
- Geschikt als oefenproject of als basis voor uitbreiding met meer spellen.

---

## Technische details

- HTML5 + CSS3 + puur JavaScript (ES6+).  
- Client-side logica voor kaart-generatie, puntentelling, speelflow.  
- Geen externe bibliotheken (tenzij je die later toevoegt).  
- De live demo draait via GitHub Pages.
